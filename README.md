\# Информационная система Кондитерская "Сладкий рай"



Курсовой проект. Предназначен для автоматизации учета заказов и управления ассортиментом кондитерской.



\## Технологии

\* Язык программирования: C#

\* Фреймворк интерфейса: Avalonia UI

\* База данных: Microsoft SQL Server

\* ORM: Entity Framework Core
